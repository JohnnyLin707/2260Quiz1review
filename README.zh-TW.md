## 功能特點

- **一頁一張投影片** —— 共 87 個獨立頁面。
- **課程投影片原圖** —— 每個頁面頂端都有真實投影片的整寬掃描圖（共 99 張）。純展示：不可點擊，且永遠依螢幕寬度自動縮放。
- **中英對照** —— 每一條原文後面緊跟中文翻譯。
- **教材答案醒目標示** —— 標準答案使用暖色強調區塊，投影片要點做成帶編號的低刺激卡片，中文行使用柔和薄荷底色。
- **模擬考題** —— 投影片頁面上有 205 道點擊展開的題目（附答案與出處），另有 4 道附輸入框的簡答題。
- **作答自測** —— 一個要點一個輸入框，自動批改：要點順序不限，英文或中文作答都接受，並會提示漏掉的關鍵字。
- **可搜尋導覽** —— 可折疊側邊欄支援即時篩選，每個單元頁也附關鍵字過濾框。
- **鍵盤快捷鍵** —— `←` 上一頁，`→` 下一頁，`Esc` 回到首頁。
- **進度條** —— 顯示目前在本單元中的進度。
- **響應式與動效** —— 捲動淡入、光球背景、水波紋點擊效果、頁面轉場動畫。
- **零依賴** —— 純 HTML / CSS / 原生 JavaScript，無須建置、無須 npm、不使用框架。

## 練習模組

| 練習 | 位置 | 題數 | 輸入框 |
|------|------|:----:|:------:|
| 指令週期填空題 | 首頁 `index.html` | 10 | 12 |
| Quiz1importantShortAnswer | `pages/Quiz1importantShortAnswer.html` | 4 | 19 |

兩套練習都會自動批改你所寫的內容：

- **一分一個輸入框** —— 框的數量永遠等於該題的配分／要點數。
- **順序不限** —— 任何一個框都可以對應到任何尚未使用的要點。
- **批改寬鬆** —— 不評大小寫、空格與完整句子；英文或中文作答都接受，改寫也算對。
- **簡寫算對** —— 例如寫 `25` 可對應「11001 in binary equals 25 in decimal」，寫 `RAM` 可對應「Memory (RAM) size」。
- **列出缺少的關鍵字** —— 讓你清楚知道該背哪些詞。
- **操作按鈕** —— `Check` 批改、`Show answers` 看標準答案、`Clear` / `Reset` 重來，`Ctrl`+`Enter` 快速檢查。

## 使用方式

### 方式一 —— 直接開啟
雙擊 `index.html` 以瀏覽器開啟即可。可用，但部分瀏覽器會限制 `file://` 下的頁面跳轉。

### 方式二 —— 本機伺服器（推薦）
```bash
cd 2260Quiz1review
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

### 方式三 —— GitHub Pages
將儲存庫推送到 GitHub，然後進入 **Settings → Pages → Build and deployment → Deploy from a branch**，選擇 `main` / `/ (root)`。網站會發布於 `https://<使用者名稱>.github.io/<儲存庫名稱>/`。

## 說明

- 內容逐字摘錄自課程投影片（`Intro to HW v2.pdf`、`Ch01v2a.pdf`）；PDF 原始檔案**不在**本儲存庫中。`Ch01v2a-images/` 與 `Intro to HW v2-images/` 下的圖片是從這些 PDF 匯出的頁面掃描圖。
- 中文翻譯、模擬考題與標準答案僅為複習輔助教材，考試前請務必與官方投影片及授課教師的要求核對。
- 自動批改以關鍵字比對為基礎並刻意設得寬鬆，它是「幫助記憶」的工具而非嚴格的閱卷標準：某個框打勾代表「你寫到了這個要點」，不代表「這是唯一正確的寫法」。
