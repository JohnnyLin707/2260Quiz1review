Question 9 · 4 marks

Convert the binary number 11001 to decimal. Show all your working.

把二进制数 11001 转换为十进制，并写出全部计算过程。

TEXTBOOK SOURCE · 教材原文

  • Multiply each bit by its decimal value (power of 2) and add the results.把每一位乘以其十进制权值（2 的幂）后相加。
  • Example from the slide: 1101 0101 → 128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = 213.课件示例：1101 0101 → 128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = 213。
Source: “Intro to HW v2.pdf” — Page 7 (Binary and Decimal Numbers Conversion: Binary to Decimal)

Question 10 · 2 marks

Give 4 items from the system specifications that one should consider and evaluate when purchasing a computer system.

购买计算机系统时，应从系统规格中考虑并评估哪 4 项？

TEXTBOOK SOURCE · 教材原文

  • Processor – central processing unit (CPU): the chip that processes most of the data and instructions for the entire system.处理器（CPU）：为整个系统处理大部分数据与指令的芯片。
  • Primary storage (main memory): provided by RAM, temporary (volatile) storage for data and instructions being processed.主存：由 RAM 提供，用于临时存放正在处理的数据与指令。
  • Secondary storage (permanent storage): enables data to persist after the machine is turned off — hard drive, SSD, CD, DVD, USB drive.外存：关机后数据仍然保留 —— 硬盘、固态硬盘、光盘、U 盘等。
  • Motherboard (system board): contains the CPU, expansion slots and other devices; all devices communicate with it.主板（系统板）：容纳 CPU、扩展槽与其他设备，所有设备都通过它通信。
Source: “Intro to HW v2.pdf” — Pages 15, 17, 19, 20 (Motherboard, Processor and Chipset, Storage Devices, Primary Storage)

Question 11 · 4 marks

What is the information held inside a program counter and when will its value be increased?

程序计数器中保存的是什么信息？它的值什么时候会增加？

TEXTBOOK SOURCE · 教材原文

  • A program consists of a set of instructions stored in memory.程序由存放在存储器中的一组指令组成。
  • The processor reads (fetches) instructions from memory and executes each instruction.处理器从存储器读取（取）指令并执行每一条指令。
  • Typically the program counter (PC) holds the address of the next instruction to be fetched.通常由程序计数器（PC）保存下一条待取指令的地址。
  • PC is incremented after each fetch.每次取指后 PC 都会递增。
Source: “Ch01v2a.pdf” — Pages 13 and 15 (Instruction Execution, Instruction Fetch and Execute)

Question 12 · 7 marks

Describe how the principle of locality can be applied in multilevel memory structure.

说明局部性原理如何应用于多级存储器结构中。

TEXTBOOK SOURCE · 教材原文

  • Memory references by the processor tend to cluster.处理器的存储器访问倾向于成簇（集中）出现。
  • Data is organized so that the percentage of accesses to each successively lower level is substantially less than that of the level above.数据的组织方式使得：越往下一级，处理器对它的访问比例显著低于上一级。
  • Can be applied across more than two levels of memory.该原理可应用于两级以上的存储器结构。
  • Going down the hierarchy: decreasing cost per bit, increasing capacity, increasing access time, decreasing frequency of access to the memory by the processor.沿层次向下：每比特成本递减、容量递增、访问时间递增、处理器访问频率递减。
  • Design constraints on a computer’s memory: how much, how fast, how expensive.存储器设计的三个约束：容量多大、速度多快、成本多高。
  • When all accesses hit Level 1 the average access time is T1; when none hit it is T1 + T2 (hit ratio).全部命中第一级时平均访问时间为 T1；全部未命中时为 T1 + T2（命中率）。
Source: “Ch01v2a.pdf” — Pages 33, 35, 36, 37 (Memory Hierarchy Design Constraints, The Memory Hierarchy, Performance of a Two-Level Memory, Principle of Locality)
