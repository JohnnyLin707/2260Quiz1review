Figure 1.3 — Characteristics of a Hypothetical Machine图 1.3 —— 假想机器的特征

  • (a) Instruction format: Opcode (bits 0–3) + Address (bits 4–15)(a) 指令格式：操作码（第 0–3 位）+ 地址（第 4–15 位）
  • (b) Integer format: S = sign bit (bit 0) + Magnitude (bits 1–15)(b) 整数格式：S = 符号位（第 0 位）+ 数值位（第 1–15 位）
  • (c) Internal CPU registers(c) CPU 内部寄存器
  • Program counter (PC) = Address of instruction程序计数器（PC）= 指令的地址
  • Instruction register (IR) = Instruction being executed指令寄存器（IR）= 正在执行的指令
  • Accumulator (AC) = Temporary storage累加器（AC）= 临时存储
  • (d) Partial list of opcodes(d) 操作码（部分列表）
  • 0001 = Load AC from memory0001 = 从存储器加载 AC（把数据从内存读入累加器）
  • 0010 = Store AC to memory0010 = 把 AC 存入存储器（把累加器内容写回内存）
  • 0101 = Add to AC from memory0101 = 从存储器相加到 AC（把内存数据加到累加器）
Source: “Ch01v2a.pdf” — Page 17, Figure 1.3 (Stallings, Computer Organization and Architecture)
