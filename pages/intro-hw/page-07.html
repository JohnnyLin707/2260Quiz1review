Binary and Decimal Numbers Conversion: Binary to Decimal

二进制与十进制数的转换：二进制转十进制

Excerpted from “Intro to HW v2.pdf” — Page 7

Original Content (verbatim)

Binary position: 8 7 6 5 4 3 2 1二进制位序号：8 7 6 5 4 3 2 1

Decimal value: 27  26  25  24  23  22  21  20十进制权值：2⁷ 2⁶ 2⁵ 2⁴ 2³ 2² 2¹ 2⁰

Example: 1101 0101
 2^7 x1 + 2^6 x1 + 2^5 x0 + 2^4 x1 + 2^3 x0 + 2^2 x1 + 2^1 x0 + 2^0 x1
   =  128   +   64    +    0    +   16   +    0    +    4    +   0     +    1
   =   213

例：1101 0101，按位乘以 2 的幂后相加：128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = 213。

Multiply each bit by its decimal value (power of 2) and add the results. For 1101 0101: 128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = 213.

把每一位乘以其对应的十进制权值（2 的幂）后相加。例如 1101 0101：128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = 213。
